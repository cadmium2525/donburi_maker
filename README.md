# 🍚 どんぶりメーカー

好きな丼をつくって、かわいく加工して、SNSでシェアできるブラウザゲームです。
ビルド不要の静的サイト（HTML / CSS / JavaScript + Canvas）なので、そのまま GitHub Pages で公開できます。

## あそびかた

1. **器をえらぶ** — かたち（定番・深め・平ため）と、朱塗り・藍の唐草・青海波・さくら・ゆめかわ水玉・織部・粉引・天目・九谷風など12デザイン
2. **ごはんをよそう** — 炊飯器の中をしゃもじで長押し → 押すほどたっぷりすくえる → 器まで運んで離す。器からすくって炊飯器に戻すこともOK。グラム数・盛り表示（少なめ〜ギガ盛り）・カロリーつき
3. **トッピング** — 90種以上の具材を1つずつのせる
   - 例：とんかつ／溶き卵(半熟とじ)／生卵／卵黄／温泉卵／目玉焼き／三つ葉／丼つゆ／マグロ／中トロ／いくら／うに／エビ天／かき揚げ／麻婆豆腐／中華あん…
   - 「のせる」「うごかす」「とる」ツール、大きさ調整、ひとつ戻す
   - 粒もの（ねぎ・ごま・いくら等）はタップやなぞりでパラパラ、ソース類（溶き卵・タレ・マヨ等）はなぞってかける
4. **加工する** — フィルター（シズル感・ふんわり・ゆめかわ・エモフィルム・韓国カフェ・昭和レトロ…）、細かい調整（明るさ・彩度・ピンク・ふんわり・光もれ・粒子・周辺減光など）、スタンプ、丼の名前、フレーム（チェキ風・ハートレース・フィルム・マガジン…）、テーブル背景・お箸・湯気
5. **シェアする** — 具材から丼の名前を自動判定（カツ丼・親子丼・海鮮丼・天丼・麻婆丼・三色丼…）。ハッシュタグと投稿文を自動生成（ON/OFF・追加・文面チェンジ可）。
   - 📱 画像つきでシェア（スマホの共有シート → Instagram / X / LINE など）
   - 📸 画像保存、𝕏・Threads・LINE への投稿文シェア、投稿文コピー

## GitHub Pages で公開する

**方法A（おすすめ）: GitHub Actions**
1. このブランチを `main` にマージ
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定
3. `main` に push されるたびに `.github/workflows/pages.yml` が自動デプロイします

**方法B: ブランチから直接**
Settings → Pages → Source を **Deploy from a branch**、ブランチ `main` / フォルダ `/ (root)` にするだけでもOKです。

公開URL: `https://<ユーザー名>.github.io/donburi_maker/`

## ローカルで動かす

ES Modules を使っているので、`file://` ではなく簡易サーバーで開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `css/style.css` | デザイン |
| `js/app.js` | 画面遷移・操作 |
| `js/bowls.js` | 器・ごはん・背景・お箸・湯気の描画 |
| `js/rice.js` | 炊飯器としゃもじ（ステップ2） |
| `js/ingredients.js` | 具材ライブラリ（すべてCanvasで描画） |
| `js/scene.js` | 具材の配置・合成 |
| `js/edit.js` | フィルター・フレーム・スタンプ |
| `js/share.js` | 丼名判定・ハッシュタグ・投稿文 |

具材を増やすときは `js/ingredients.js` に `add({ id, name, cat, kind, S, draw })` を1つ追加するだけです。
`kind` は `piece`（1個ずつ）・`sprinkle`（パラパラ）・`sauce`（なぞってかける）の3種類。
